Come and learn how to use git, GitHub, and GitHub CoPilot. Topics we will focus on:

- What is git and why would you want to use it
- What is GitHub
- How to get a GitHub account and student access to CoPilot
- How to use git in normal engineering workflows and agentic workflows
- How to use GitHub CoPilot to review your code and build apps.

It is recommended that you bring your own laptop and signup for a GitHub account before coming (I would recommend using your personal email address).
